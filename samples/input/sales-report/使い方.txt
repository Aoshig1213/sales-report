売上集計ツール 使い方
====================

1. input フォルダに、売上の CSV または Excel ファイルを入れます。
   （最初はサンプルのファイルが入っています。自分のデータで試すときは消してください）

2. 「売上集計.bat」をダブルクリックします。

3. 集計が終わると output フォルダが開き、「売上集計_日付_時刻.xlsx」ができています。


■ 入力ファイルの形式

・1行目に見出し、2行目から明細を入れてください。列の順番は自由です。
・必要な列: 日付、店舗、商品コード、商品名、単価、数量
・あれば使う列: カテゴリ、金額（金額がある場合は 単価 × 数量 と合っているかチェックします）
・見出しは「売上日」「店舗名」「品番」「品名」「分類」なども同じ列として読みます。
・CSV の文字コードは UTF-8、Shift_JIS のどちらでもかまいません。
・Excel は1枚目のシートを読みます。

■ 読み込めない行があったとき

処理は止めずに、読めた行だけで集計します。
読めなかった行は、帳票の「エラー」シートにファイル名・行番号・理由が出ます。
元のファイルを直してから、もう一度実行してください。

■ 動かないとき

Java 21 以降が必要です。「Java が見つかりません」と出たら、次のページからインストールしてください。
https://adoptium.net/ja/temurin/releases/
